Terminal Chess

Pair the reviewed local bridge. Your Chess.com login stays in the browser.

  1. Run chess and click Browser setup → Copy token.
  2. Paste the token below and click Pair.
  3. Log in to Chess.com and open its online play page.
  4. Click the extension icon on that tab to bind it explicitly.

This is an unofficial website adapter. It does not supply engine advice or start games by itself. Missing website controls stop the action.
