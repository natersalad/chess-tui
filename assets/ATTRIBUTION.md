# Wooden chess sounds

Source: **Board Game Wood Piece Placement**, by El Final Boss / Jeff Final Boss (metadata: Final Boss Editing).

- Source page: https://licensing.routenote.com/sound-effect/board-game-wood-piece-placement
- License: **CC0**, as stated on the source page, checked 2026-10-10.
- Source describes an original recording of a chess piece placed on a wooden board.
- Download: https://storage.googleapis.com/routenote-licensing-storage/public/sound_effects/7292/546119__el-boss__piece-placement.mp3

Converted to mono 48 kHz PCM WAV, adjusted gain, and arranged into short rhythms. `piece-place.wav` uses one recorded placement; `capture.wav`, `check.wav`, `checkmate.wav`, and `game-end.wav` use distinct sequences of the same physical sample. These event rhythms are local arrangements, not separate recordings of those game events.

`invalid-drop.wav` remains the original locally synthesized error cue.
